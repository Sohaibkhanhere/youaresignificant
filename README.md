# Sincerely You Are Significant, Inc. (SYS)

Official website for **Sincerely You Are Significant, Inc.**, a 501(c)(3) human services nonprofit agency founded and led by Bianca Reid in Stockbridge, GA.

## 🌟 Mission & Guiding Vision
> *"Write the vision and make it plain, that he may run who reads it."* — Habakkuk 2:2 (NKJV)

Sincerely You Are Significant, Inc. is dedicated to:
- **Empowering Individuals**
- **Strengthening Families**
- **Building Community**
- **Advancing Kingdom Impact**

---

## 📁 Website Structure
- `index.html` — Homepage (Hero, Mission, 4 Pillars, Founder intro, Impact, CTAs)
- `about.html` — About Us (Organizational narrative, core values, approach)
- `services.html` — Services & Programs (Youth, Families, Seniors, Community)
- `founder.html` — Founder Profile (Bianca Reid, vision, personal values)
- `community.html` — Community & Events (Photo gallery, events, volunteer info)
- `contact.html` — Get Support & Contact (Inquiry form, Jonesboro office info, crisis hotlines)
- `support.html` — Support Our Mission (501(c)(3) giving info, donation options)
- `privacy.html` — Privacy Policy & Accessibility Statement
- `css/main.css` — Centralized responsive design system
- `js/main.js` — Navigation, smooth scroll, form validation, accessible modals
- `images/` — Authentic photography and assets

---

## 🚀 Running Locally
You can serve the static site using any local HTTP server:

```bash
# Using npx serve
npx serve . -p 3000

# Or with Python
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
